# Политика конфиденциальности

Редакция от 5 октября 2026

Эта политика описывает, какие данные обрабатывает приложение VexVPN для iPhone, кому они передаются и как ими управлять. У приложения нет аккаунтов и аналитики. Сервер VexVPN получает адрес для уведомлений, только если вы их разрешили и добавили подписку VexVPN (см. «Уведомления»).

## Что хранится на устройстве

Ссылка подписки, идентификатор устройства и ключ шифрования локального кэша хранятся в защищённом хранилище iOS (связке ключей). Список серверов и сведения о подписке — в зашифрованном файле, доступном приложению и его сетевому расширению. Настройки подключения, тактильного отклика и скрытия экрана хранятся в обычных локальных настройках. Приложение не синхронизирует эти данные через iCloud.

Идентификатор устройства приложение создаёт само. Он остаётся в связке ключей и после удаления приложения, чтобы провайдер не считал переустановленное приложение новым устройством. Ссылка подписки и серверы после переустановки стираются.

## Что получает провайдер подписки

При добавлении и обновлении подписки приложение обращается только по адресу, который вы указали. Вместе с запросом провайдер получает название и версию клиента (VexVPN, номер сборки), идентификатор устройства, версию iOS и модель iPhone — так провайдеры ограничивают число устройств. Провайдер также видит IP-адрес и обычные технические параметры соединения. Дальнейшую обработку определяет политика провайдера.

Ссылки серверов, вставленные напрямую или считанные из QR-кода, никуда не отправляются: приложение подключается по ним без запроса подписки.

## Файл настроек приложения

Несколько раз в сутки, при открытии приложения и при добавлении подписки, приложение загружает публичный файл настроек с GitHub (если GitHub недоступен — его копию с jsDelivr): список адресов подписок, которые можно добавить, и сведения о новых геоданных — списках доменов и IP-адресов, по которым работают правила маршрутизации подписки. Новые геоданные приложение скачивает с GitHub не чаще раза в сутки и подключает при следующем включении VPN. Запросы одинаковые для всех: ссылка подписки, идентификатор устройства и сведения о подключении не передаются. GitHub и jsDelivr видят IP-адрес и обычные технические параметры соединения.

## Уведомления

Напоминания о сроке доступа приложение создаёт само на устройстве: за 12 часов, за 6 часов и за час до окончания и в момент окончания. Они никуда не отправляются.

Если вы разрешили уведомления и добавили подписку VexVPN, приложение получает от Apple адрес для уведомлений этого iPhone (push-токен) и передаёт его серверу VexVPN вместе с запросом подписки. Сервер хранит токен вместе с подпиской и присылает уведомления о работе сервиса: о сроке доступа, новых версиях приложения, новых серверах, плановых работах и сбоях. Уведомления доставляет служба Apple Push Notification service.

Чтобы не получать уведомления, выключите «Настройки» → «Уведомления» в приложении или уведомления VexVPN в настройках iOS, либо нажмите «Удалить данные». Токен не передаётся другим провайдерам и третьим лицам и не используется для рекламы других сервисов.

## Камера и фото

Камера включается только на экране «Сканировать QR-код», чтобы прочитать код; изображение не сохраняется и не передаётся. При выборе фото приложение получает только выбранный снимок, без доступа ко всей медиатеке.

## Подключение VPN

При включении VPN сетевое расширение передаёт трафик устройства на выбранный сервер провайдера. Сервер и DNS-сервисы получают данные, необходимые для передачи и разрешения адресов. Часть соединений может идти напрямую согласно правилам подписки. Приложение не обещает полную анонимность.

Для замера пинга приложение устанавливает TCP-соединение с адресами серверов из подписки. После подключения выполняется одна проверка доступа к интернету; ссылка подписки и идентификатор устройства при этом не передаются.

## Разработчик и третьи лица

Разработчик не продаёт данные, не передаёт их третьим лицам и не использует сведения о трафике для рекламы или профилирования. Журналы посещений не ведутся. Кнопки «Личный кабинет» и «Поддержка» открывают страницы провайдера в браузере; к ним применяются правила провайдера.

## Журнал диагностики

Запись журнала по умолчанию выключена. Журнал хранится на устройстве, не содержит ссылки подписки, ключей серверов, идентификатора устройства и истории посещений и уходит только тем способом, который вы выберете в меню отправки.

## Управление данными

«Настройки» → «Удалить данные» стирает ссылку, серверы, сведения о подписке и настройки приложения на этом iPhone. «Очистить журнал» удаляет записи журнала. Данные у провайдера управляются в его личном кабинете или через его поддержку.
